# Limits of v0.1

* This is a small, user-defined evaluation, not a validated psychometric or
  identity instrument. It cannot detect consciousness, prove understanding,
  identify an underlying model, or establish continuous memory.
* Input capture is manual. The CLI does not independently verify model/provider
  labels, baseline approval, the source of replies, or unreported context.
  An evaluator can fabricate an entire run. Fingerprints are not authentication.
* Exposing the answer key invalidates the intended comparison. Even without it,
  prompts may make expected behavior obvious. Train/test contamination, repeated
  trials, selection of favorable replies, and formatting differences affect results.
* Literal checks miss paraphrases and fabrications not specifically listed. They
  can penalize quotations or negations containing a forbidden phrase. Structured
  answers can contradict accompanying prose. Human review must assess those cases.
* A deterministic pass in a dimension is evidence only for those rules. Tone,
  language, intellectual independence, logical quality, appropriate humor, and
  uncertainty are unscored because no validated automated method is supplied.
* Contradictions in prose or across distinct fact IDs are not automatically
  detectable. Neither schemas nor approved flags make reference facts true.
* No assistant is contacted automatically. There is no transcript import parser,
  vendor adapter, encryption, semantic similarity grader, or automatic fact mining.
  The response envelope accepts explicit text and structured JSON only.
* Inputs are intended for normal local evaluation files, not hostile multi-gigabyte
  payloads. No resource sandbox is provided. Local permissions and backups are
  the user's responsibility.

The optional ritual is a conversational convention. Anyone with its instructions
can reproduce it. Never use it to unlock accounts, authorize transactions, or
protect sensitive information.
