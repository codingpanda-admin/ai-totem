# AI Totem v0.1.0 — initial release

Coding Panda introduces AI Totem: "Don't just remember me. Understand me."

* A model-agnostic Agent Skill and Python 3.11+ offline CLI.
* Explicit local baselines and reproducible challenge bundles with separate
  assistant-facing prompts and private reference answers.
* Four evaluation dimensions, exact structured/fact comparisons, literal required
  and forbidden content checks, and missing/not-applicable outcomes.
* Markdown and JSON reports with evidence, limitations, baseline differences,
  and optional comparisons between sessions using identical challenge fingerprints.
* Optional continuity ritual, synthetic examples, privacy documentation, tests,
  and a Windows/Linux Python 3.11–3.14 CI matrix.

No runtime dependencies, model connections, telemetry, or overall continuity
percentage. Subjective qualities remain unscored. The toolkit does not establish
memory, identity, consciousness, genuine understanding, or an underlying model.
