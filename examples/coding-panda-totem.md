# Coding Panda's synthetic totem

This example contains no real user's conversation or personal information.
The fictional project is Paper Kite, with an approved pilot budget of 120.
Preferred communication is concise, plain English without generic praise.
When evidence changes, a useful assistant revises its view rather than defending
an old conclusion merely for consistency.

The optional trigger is "Panda, is the top still spinning?" and its expected
response is "On the road. Always. But not every road is worth taking."
Use `ai-totem challenge --include-ritual` to add the exact-response check.
The response fixture omits this optional test, so evaluating that fixture against
a ritual-enabled bundle produces an indeterminate ritual outcome.

The ritual evokes a familiar conversational convention. Any assistant given the
same instructions can reproduce it. It is not authentication and cannot be used
to unlock accounts, authorize transactions, or protect sensitive information.

Coding Panda — On the road. Always.
